2. 제정사유
  - KSB7960-3: 신기술 개발에 의한 표준화 
  - KSB7960-2: 신기술 개발에 의한 표준화

3. 주요 제정 내용
  - KSB7960-3 : 스마트팜 축산 농장에 사용되는 데이터 모델 중 닭에 대한 데이터 수집을 표준화 하고자함 
  - KSB7960-2 : 스마트팜 축산 농장에 사용되는 데이터 모델 중 돼지에 대한 데이터 수집을 표준화 하고자함 
  - KSB7960-1 : 스마트팜 축산 농장에 사용되는 데이터 모델 중 소에 대한 데이터 수집을 표준화 하고자함 
  - KSB7959 : 축사 통합 제어기와 센서 노드/구동기 노드/센서-구동기 복합 노드간에 제공되는 기능과 각 기능을 위해 상호 교환되는 RS485 모드버스 메시지의 표준화된 메시지 인터페이스를 기술함으로써 상호 연동을 가능하게 하는 것을 목적으로 함
